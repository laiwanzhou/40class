## 旧 Kaggle 提交

使用 `kaggle/submission.csv`，这是已经计分的原文件，不是新测试集的答案。
本次未重新上传，也未修改该 CSV。确认比赛选中的最终提交就是这份文件。

## 主办方发新测试集后

1. 按根目录 README 建立独立 Python 环境，安装固定版本依赖。
2. 解压新数据，保留模态文件名和帧时间戳。准备主办方的空预测 CSV。
3. Windows 在包目录打开 PowerShell，执行：

```powershell
& .\inference.ps1 -DataDir 'D:\new_data' -TestCsv 'D:\new_data\test.csv' -OutputDir 'D:\new_result'
```

4. 等待命令成功退出。Linux/Bash 对应命令在根 README。
5. 检查 `D:\new_result\report.json` 中 `partial` 为 `false`、行数等于官方 CSV。
6. 提交 `D:\new_result\submission.csv`，保存报告和日志。

不要传 `--max-rows`，不要复用已有输出目录，不要手改 prediction，不要复制旧测试集
缓存。报错时不要提交残缺结果；先检查环境、数据目录和官方输入格式。

模型从新原始文件自动提取姿态、ROI 和传感器特征，使用固定 Student 输出结果。
全部权重在一个 56.47 MB checkpoint 中，含 YOLO；不下载额外模型，不调用 LLM。
临时缓存由程序自动生成，默认清理。保留缓存调试时不得公开上传其中的比赛数据。
